# RegOS Engineering Manual

The Engineering Manual defines the engineering standards used to design, implement, test, and evolve the RegOS platform.

Every engineer contributing to RegOS is expected to understand and follow the standards described in this manual.

## Reading Order

1. Engineering Philosophy
2. Repository Architecture
3. Business Modeling
4. Implementation Standards
5. Testing
6. Engineering Workflow

The documents should be read in this order by all new engineers before contributing to the platform.

The Engineering Manual is normative.

Architectural decisions, implementations, and pull requests are reviewed against these standards.
