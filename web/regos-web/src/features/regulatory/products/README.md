# Product Feature

## Responsibilities

- List Products
- Register Products
- View Product Details (planned)

## Folder Structure

- api/ - Backend API calls
- components/ - Product UI components
- constants/ - Product reference data
- hooks/ - React Query hooks
- pages/ - Route components
- types/ - TypeScript models
- validation/ - Zod schemas

## Architecture

Page
↓
Components
↓
Hooks
↓
API
↓
Backend
